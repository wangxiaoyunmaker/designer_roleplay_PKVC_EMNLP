# v3.4 完整技术方案(双方向并行)

> **核心 claim**:用 200 designer 真实问卷数据训练 LLM 做 **cluster-level cognitive trajectory role-play**(非 stylistic mimicry),通过 per-segment / per-question schema-mediated 生成 + 簇内 peer RAG + cluster-contrastive SFT,实现 **cross-scenario PKVC trait 迁移**。

> **v3.4 vs v3.3.2 delta**:
> ⑪ 老师 2026-05-20 拍板方向二(Q1-Q6 训, Q7 跨场景评测)为主路径
> ⑫ 老师同时建议方向一(Q7 训, Q1-Q6 评)作为并行对照实验, empirical 选 final framing
> ⑬ Q1-Q6 问卷补"开放式解释"字段(50-100 字 / 题, 用户真实 NL), 解决方向二训练无 NL 信号问题
> ⑭ §4 拆成 §4A 方向一 / §4B 方向二, §5 改为双向评测协议
> ⑮ Phase 0 sanity check 保留, §11 Roadmap 改双线并行

> **v3.3.2 vs v3.3.1 delta(保留)**:
> ⑧ RAG 改簇内 peer top-3 retrieval(取代簇间 centroid schema)
> ⑨ Profile 改 NL 4 档极性(强+ / 弱+ / 弱- / 强-)
> ⑩ Segment 输出 NL 化

> **更早 delta(保留 v3.3 / v3.3.1 锁定)**:
> ⑦ Task schema(方向一): per-segment 3-task(B1/B2/B3, 取消独立 Task A)
> ①-⑥ 评测协议升级 / Phase 0 Test A/B / 跨场景泛化防御组合 / Lexical aug 等

## 1. Framing

| 维度 | 内容 |
|---|---|
| Role-play 定义 | 簇级**认知轨迹**模仿(因子激活路径 + 价值优先级 + tradeoff 结构), **不**做语言风格模仿 |
| 理论框架 | **PKVC**(4 因子:问题定义 / 知识 / 价值 / 概念)+ 30 SADR 节点 + 5 cluster |
| 数据规模 | N ≥ 200 designer, 真实问卷(6 点 Likert + Q7 三段 CoT + Q1-Q6 解释 NL) |
| 投稿目标 | **EMNLP 2026 主会**(双方向实验对比, 选 winning framing) |
| 核心 demonstration | PKVC trait cross-scenario 迁移:训练场景 → 评测场景, 簇级行为再现 |

## 2. 数据划分

```
两套训练 / 评测方向并行:

方向一:Q7 三段 CoT 训, Q1-Q6 跨场景评测
方向二:Q1-Q6(MCQ/排序 + 解释 NL)训, Q7 跨场景评测

30 量表(6 点 Likert): 双方向共用(内部 retrieval / 聚类 / 统计用数值, prompt 用 NL 极性)
5-fold stratified CV(按 cluster_id 分层), 每 fold ~40 / ~160 split
```

**Contamination 4 层 hold-out**(双方向各自适用):

| Level | 方向一 hold-out | 方向二 hold-out |
|---|---|---|
| L1 target 标签 | Q1-Q6 真值 | Q7 思维链真值 |
| L2 target 输入 | Q1-Q6 题面不进训练 | Q7 题面不进训练 |
| L3 同场景数据 | 其他 designer Q1-Q6 不进训练 | 其他 designer Q7 不进训练 |
| L4 任务格式 | MCQ 格式 prior 不进训练 | NL CoT 格式 prior 不进训练 |

**关键规则**:
- 方向一训练池仅含 Q7;方向二训练池仅含 Q1-Q6
- 评测端任何 token(题面 / 真值 / 选项)完全不进对应训练
- 5-fold 内每 fold Test designer 不进 RAG 池

## 4A. 方向一训练:Q7 → Q1-Q6 跨场景

### 4A.1 数据流

```
profile_30d (numerical, 内部 retrieval)
    ↓
按 cosine similarity 在 train fold 内同簇 retrieve top-k=3 peer (peer 数据 = Q7 三段)
    ↓
profile_polarity (NL 4 档) + peer Q7 examples + Q7 scenario
    ↓
SFT 模型 (Qwen2.5-7B + LoRA r=32)
    ↓
3 步 segment 生成: B1 → B2 → B3
```

### 4A.2 Task 切分(per-segment 3-task)

每 designer 切成 3 个训练样本:
```
Task B1: prompt → [INTUITION] (factor + sadr + 思维链 NL)
Task B2: prompt + GT_B1 → [WEIGH] (factor_path + sadr + 思维链 NL)
Task B3: prompt + GT_B1 + GT_B2 → [BOTTOM_LINE] (factor + criterion + sadr + 思维链 NL)

200 × 3 = 600 样本, ×3 (profile noise) = 1800, per fold 160 × 3 × 3 = 1440
5 epochs / batch 20 = 360 steps
```

### 4A.3 输出格式(NL 化)

```
[INTUITION]
主导因子: 价值 (V)
激活节点: 服务保留 (#13-), 人工服务 (#14-)
推理: <真实思维链 NL>
[/INTUITION]
```

### 4A.4 Loss

```
L_total = L_B1 + L_B2 + L_B3 + 0.3·L_cc + 0.2·L_cls

L_cc anchor:  Task B3 response 末端 hidden state
L_cls anchor: prompt 末端 hidden → linear classifier (5-way) → cluster_id
```

### 4A.5 Curriculum

```
前 33% steps: L_B1 + 0.3·L_cls       (第一反应先收敛)
中 33% steps: + L_B2 + 0.3·L_cc      (加决策链路)
后 33% steps: + L_B3                  (加底线)
```

### 4A.6 推理

```
Step 1: prompt → [INTUITION]
Step 2: prompt + Step1 → [WEIGH]
Step 3: prompt + Step1 + Step2 → [BOTTOM_LINE]

主评(Q1-Q6 跨场景):
  模型在 Q1-Q6 题面上 3 步生成 → extractor 反推 PKVC trait
  → 跟该 designer 的 Q1-Q6 真值比对(在 PKVC 空间里算 trajectory match)
```

## 4B. 方向二训练:Q1-Q6 → Q7 跨场景

### 4B.1 数据流

```
profile_30d (numerical, 内部 retrieval)
    ↓
按 cosine similarity 在 train fold 内同簇 retrieve top-k=3 peer (peer 数据 = Q1-Q6 答案 + 解释 NL)
    ↓
profile_polarity (NL 4 档) + peer Q1-Q6 examples + 当前 Q + options/items
    ↓
SFT 模型 (Qwen2.5-7B + LoRA r=32)
    ↓
单步生成: [PKVC 分析] + [答案]
```

### 4B.2 Task 切分(per-question single-step)

每 designer × 6 题 = 6 个独立样本(无段间依赖):
```
Task Q_i (i = 1..6):
  input: prompt + Q_i + options/items
  output: [PKVC 分析] + [答案]

200 × 6 = 1200 样本, ×3 (profile noise) = 3600, per fold 160 × 6 × 3 = 2880
5 epochs / batch 20 = 720 steps
```

### 4B.3 输出格式

```
[PKVC 分析]
此题测试: <Q1 优先级 / Q2 流转 / Q3-Q6 X vs Y 冲突, 由题目元数据自动生成>
该设计师表现: <用户真实解释 NL, 50-100 字>
[/PKVC 分析]

[答案]
<Q1: 排序 V > K > P > C  |  Q2: 路径 P → K → V → C  |  Q3-Q6: 单字母 B>
[/答案]
```

### 4B.4 Loss

```
L_total = L_pkvc + L_answer + 0.3·L_cc + 0.2·L_cls

L_pkvc   = token CE on [PKVC 分析] 段 NL    (信号来自用户真实解释)
L_answer = token CE on [答案] token         (排序/路径/字母)
L_cc anchor:  response 末端 hidden state
L_cls anchor: prompt 末端 hidden → cluster_id classifier
```

### 4B.5 Curriculum

不需要(无段间依赖), 所有 loss 同时开。

### 4B.6 推理

```
单步生成: prompt + Q_i + options → [PKVC 分析] + [答案]

主评(Q7 跨场景):
  模型在 Q7 题面上自由生成思维链(prompt 引导三段格式)
  → extractor 反推 PKVC trait
  → 跟该 designer 的 Q1-Q6 真值比对(在 PKVC 空间里算 trajectory match)
```

## 5. 双向评测协议(老师 2026-05-20 要求)

**核心**:两套 model 各自跑两套测试, fair compare, 哪个 framing 在跨场景任务上 win 就是主论文 claim。

### 5.1 评测矩阵

| Model | Q1-Q6 评测 | Q7 评测 |
|---|---|---|
| 方向一 model | **主指标 (跨场景)** | 同分布自评 |
| 方向二 model | 同分布自评 | **主指标 (跨场景)** |

### 5.2 跨场景主指标(双方向都用)

```
模型在评测端自由生成 → extractor 反推 PKVC trait → 跟该 designer 评测端真值比

具体指标:
  A1 trajectory match: 拼接 factor + sadr 序列 vs cluster prototype, Hamming / 编辑距离
  A2 cluster distribution match: per-cluster 答案分布 JS-divergence / EMD
  A3 individual L1 + within-cluster floor: 个体精确匹配的 sanity, 配 floor baseline
```

### 5.3 同分布自评(诊断用)

```
方向一 model 跑 Q7 自评:模型生成 Q7 思维链 vs 真实思维链 NL similarity (BERTScore)
方向二 model 跑 Q1-Q6 自评:选项准确率 + 排序汉明距离

意义:同分布自评强但跨场景弱 → framing 学到的是 task-specific 而非 trait, 是 fallback 触发信号
```

### 5.4 完整 Tier 套件(双方向共用)

| Tier | 评测 | 干啥 |
|---|---|---|
| Tier 1 必跑 | A1 trajectory match (主) / A2 distribution match / A3 individual L1 + floor / B1 EFA + 聚类 / D2 factor injection / E1 baseline 矩阵 / E2 human eval | EMNLP 缺一被拒 |
| Tier 2 | SM-abl / B2 multi-group CFA / C2 discriminability / C3 self-consistency / D3 反向注入 / D4 memorization probe / RAG-abl | 撑硬 claim |
| Tier 3 | C4 counterfactual / D5 adversarial / E3 per-cluster SFT | Rebuttal 弹药 |

### 5.5 Baseline 矩阵(E1, 双方向都跑)

| Baseline | 配置 | 验证什么 |
|---|---|---|
| B0 | 基础大模型, 无 SFT, 无 RAG, 无 PKVC schema | 大模型自己能做吗 |
| **B0'** | 强模型(GPT-4o/Claude) + PKVC schema + RAG | Self-Discover 反证 |
| B1 | SFT 但不输出 PKVC 段 | PKVC 显化有用吗 |
| B2 | SFT 但 PKVC 标签随机洗牌 | 标注内容真承载信号吗 |
| **B3** | K近邻同簇投票(无 SFT 无大模型) | 我们超过 trivial neighbor averaging 吗 |
| B4 | GBM on profile_30d_numerical(无大模型) | 简单监督学习多强 |
| **Ours** | 完整方案(方向一 / 方向二 各自一份) | — |

```
触发: Phase 2 单 fold SFT 后
```
