## 2. 修订后 architecture (3 层不变, 内部实现改)

```

│  ✓ 保留: factor scores 4 维 → 直接作 conditioning             │
│       (soft prompt / prefix / cross-attention)                │
└──────────────────────────────────────────────────────────────┘
                              │
                              │  CAPS theory (Mischel 1995):
                              │  if [factor score + situation C]
                              │  then [PKVC state activation via routing]
                              ▼
┌─ Bridge Layer (动态, T_CAPS quad ontology) ───────────────────┐
│  quad = (C, s, p, o)                                          │
│    C       4 个情境 (Q3-Q6) ← 4 个 string lock 待一作 confirm │
│    s_primary    group-level top-3 trait ← option_trait_mapping│
│                       (今晚 22 entries 已就绪)                 │
│    s_secondary  factor + direction ← quad_s_secondary_assoc   │
│                       (今晚 13 robust 已 mined)                │
│    p_surface    8 词 codebook ← LLM 抽 (blocker A)            │
│    p_modulation 4 档 + bypass ← 查 p_surface 表得              │
│                       阈值 data-driven (0.06 / 0.28)           │
│    o_primary    P/K/V/C ← LLM 抽确认 (blocker A)              │
│                       hint 已就绪 (option_trait_mapping)       │
│    o_subtype    12 SADR (P1..C3) ← LLM 抽 (可选)              │
└──────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─ PKVC State Machine (4 state, theory-locked) ─────────────────┐
│  P / K / V / C 4 state runtime, 不动                          │
│  o_primary 是 quad 的 target, runtime inference target        │
└──────────────────────────────────────────────────────────────┘
```

## 4. 训练 + RAG + 评测 实施变化

### 4.1 训练

```python
# 砍 cluster, 加 trait-factor prefix
input = [
    factor_scores_4d (continuous prefix),       # 替代 cluster_id one-hot
    situation_C (string),
    s_primary (3 traits from quad),
    peer_retrieved (top-3 quad via trait cosine)  # 替代簇内 top-3
]

target = NL answer

L_total = L_lm + λ_pkvc · L_pkvc                  # 砍 L_cls
                                                  # L_cc (CAPS connection) 待评估保留
```

### 4.2 RAG (peer retrieval)

```python
# 旧: 簇内 cosine top-3
# 新: 全局 trait-similarity top-3
def retrieve_peers(D_query, target_C):
    candidates = [
        q for q in quads_all
        if q.C == target_C            # 情境匹配
        and q.designer_id != D_query   # 不自检索
        and q.designer_id in train_fold # 防 leakage
    ]
    # 按 D_query 和 q.designer_id 的 4-d factor cosine 排序
    sims = [(q, cosine(D_query.factors, q.designer.factors)) for q in candidates]
    return sorted(sims, key=lambda x: -x[1])[:3]
```
