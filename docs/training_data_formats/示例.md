# 训练格式完整 prompt 示例 (β+++ Implicit-Choice + 三轨监督 + Dual-Form)

**版本**: β+++ (2026-05-23 锁)
**示例 designer**: `D002` (当前 79 人里 NL 写得最长的)

**关键设计** (β+++):
- ⚠ Input 不暴露 MCQ 选项文本 (跟 Q7 评测形式对齐)
- ⚠ Output 三轨监督: `[PKVC 分析]` (α=0.5) + `[决策签名]` (β=0.3) + `[答案]` (γ=0.2)
- ⚠ 结构化字段全 dual-form: 自然语言主 + token 括号附
- ⚠ Peer 砍掉 decision NL 和 answer letter, 只显示 quad fields (dual-form)
- ⚠ 决策签名 paraphrase × 3 + token-level dropout 10% (防 verbatim memorize)

⚠ 所有示例的 `task_background` (C_global), `o_subtype` (cardId 子类), `p_surface` 子类映射
**当前是 placeholder** (等学姐 ⑤ + ③ + ④), 真实训练数据待学姐解锁。

## 5 个待 review 关键点 (跟 GPT/reviewer 讨论时重点)

```
1. Dual-form token 预算: input/output 都 +20%, batch_size 4→3, 训练时间 +33%
   Trade-off OK 不? 或者部分字段降级到 token-only (e.g. confidence)?

2. Peer dual-form quad 字段是否 *全* 该展示:
   o_primary 必要, o_subtype / p_modulation 可能冗余, 砍掉省 token

3. Paraphrase pool 生成:
   每个 option × 3 paraphrase 用 GPT-4o 跑 (~$5 全 Q1-Q6), 还是手动写?
   GPT 生成可能 hallucinate, 加 audit step

4. Token dropout 0.10 是否合理:
   0.05 / 0.10 / 0.15 sweep, paper §6 ablation

5. Reasoning NL ≤10 字的 designer (大多数) 怎么办:
   (a) skip 不训 (丢 ~70 designer 信号)
   (b) 训, 但置信度标 "低"
   (c) 等 E 阻塞 (NL 补长) 解了再训
   我推 (c).
```
